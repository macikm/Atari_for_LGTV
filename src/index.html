Herní ovládání (Joystick 1)

Pohyb (nahoru, dolů, vlevo, vpravo) Šipky nebo Num 8, 2, 4, 6
Tlačítko FIRE (střelba / akce) Pravý Ctrl nebo Num 0
Alternativa pro akční hry Tlačítkem Mód: BASIC / WASD v horní liště lze povolit i klávesy W, S, A, D

Systémové klávesy Atari

START klávesa F4
SELECT klávesa F3
OPTION klávesa F2 (při bootu vypíná BASIC)
RESET (Warmstart) F5
COLD RESET (studený restart) Shift + F5
EMULATOR MENU / Nastavení F1
HELP klávesa (XL/XE) F6

Práce s Atari BASICem

Fyzická klávesnice funguje přímo jako originální klávesnice počítačů Atari 800XL/130XE. Můžete psát přímo příkazy BASICu:

10 FOR I=1 TO 10
20 PRINT "ATARI WEBOS "; I
30 NEXT I
RUN
